# ДПС — макет для печати A4

Вырезанная фигура ДПСника (вид со спины, жилет с надписью «ДПС») и лист для печати.

## Файлы

| Файл | Описание |
|------|----------|
| `dps-a4-print.pdf` | **Для печати** — лист A4, 300 dpi |
| `dps-a4-print.png` | То же в PNG |
| `dps-cutout-clean.png` | Чистая вырезка на прозрачном фоне |
| `dps-6cm.png` / `dps-7cm.png` / `dps-8cm.png` | Отдельные фигуры нужной высоты |

## Размеры на листе

- **8 см** — верхний ряд (3 шт.)
- **7 см** — второй ряд (3 шт.)
- **6 см** — нижние ряды (8 шт.)

Печать: A4, без масштабирования («фактический размер» / 100%).
