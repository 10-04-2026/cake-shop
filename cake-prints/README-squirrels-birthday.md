# Топпер «С Днём Рождения!» — белочки, Ø 11 см

Печатный макет круглой картинки на листе **A4**.

## Файлы

| Файл | Назначение |
|------|------------|
| `squirrels-birthday-11cm-A4.pdf` | Лучше всего для печати (A4, 300 DPI) |
| `squirrels-birthday-11cm-A4.png` | То же в PNG |
| `squirrels-birthday-11cm-A4.jpg` | То же в JPEG |
| `squirrels-birthday-11cm-circle.png` | Только круг 11 см (без листа) |
| `squirrels-birthday-source.jpg` | Исходное фото |

## Параметры

- Лист: A4 (210 × 297 мм), белый фон
- Круг: диаметр **11,0 см**, по центру листа
- Разрешение: **300 DPI** (2480 × 3508 px)

## Печать

1. Откройте PDF или PNG.
2. Печатайте в масштабе **100%** (без «вписать в страницу»).
3. Вырежьте по контуру круга.

Пересобрать макет: `python3 scripts/make-squirrels-birthday-topper.py`
