# Фото стилей с Pexels (бесплатно)

С этого компьютера автозагрузка с Pexels/Pixabay иногда **не проходит** (таймаут сети). Скачайте вручную — 2 минуты:

1. Откройте ссылку → **Free download** (бесплатно, лицензия Pexels).
2. Сохраните файл в папку `design-images/` с **точным именем** из таблицы.

| Файл на сайте | Ссылка Pexels |
|---------------|----------------|
| `01-lambet.jpg` | https://www.pexels.com/photo/white-frosting-on-brown-cake-1028714/ |
| `02-waffle.jpg` | https://www.pexels.com/photo/close-up-photo-of-waffles-2961958/ |
| `03-italian.jpg` | https://www.pexels.com/photo/sliced-cake-on-white-ceramic-plate-2915282/ |
| `04-oval-lambet.jpg` | https://www.pexels.com/photo/white-cake-with-red-berries-on-top-2915287/ |
| `05-custom.jpg` | https://www.pexels.com/photo/beautiful-bliss-bridal-buttermilk-306071/ |

Обновите сайт: **Cmd + Shift + R**.

Или в терминале (если интернет есть):

```bash
cd "/Users/arusnazloyan/Documents/Новая папка/cake-shop"
python3 scripts/download-pexels.py
```
