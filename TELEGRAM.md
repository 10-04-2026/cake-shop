# Заявки в Telegram

## 1. Создайте бота

1. Откройте Telegram, найдите **@BotFather**.
2. Отправьте `/newbot`, придумайте имя и username бота.
3. Скопируйте **токен** (вид `123456789:AAH...`).

## 2. Узнайте CHAT_ID

**Личные сообщения вам:**

1. Напишите боту любое сообщение (например «Привет»).
2. Откройте в браузере (подставьте свой токен, без пробелов):  
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`  
   Должен открыться **текст JSON** (не пустая страница и не «сайт недоступен»).
3. В ответе найдите `"chat":{"id":123456789` — это **CHAT_ID**.

Если `api.telegram.org` не открывается — попробуйте другую сеть/VPN или узнайте id через бота **@userinfobot** (напишите ему `/start`, он пришлёт ваш id).

**Группа:**

1. Добавьте бота в группу.
2. Напишите в группе сообщение.
3. Снова откройте `getUpdates` — id группы обычно отрицательный, например `-1001234567890`.

## 3. Файл настроек

В папке `cake-shop`:

```bash
cp telegram.env.example telegram.env
```

Откройте `telegram.env` и вставьте:

```
BOT_TOKEN=ваш_токен_от_BotFather
CHAT_ID=ваш_chat_id
```

Файл `telegram.env` в git не попадает (секреты не публикуются).

## 4. Запуск сайта

**Важно:** заявки в Telegram работают только через наш сервер, не через `python3 -m http.server`.

```bash
cd cake-shop
python3 server.py 8080
```

Откройте: http://127.0.0.1:8080/

В терминале должно быть: `Telegram: настроен`.

## 5. Проверка

**Сервер запущен через `python3 server.py 8080`?** Тогда в браузере откройте:

- http://127.0.0.1:8080/api/health — должно показать `"ok": true` и `telegramConfigured: true`

Адрес **http://127.0.0.1:8080/api/order** в браузере **не откроется как страница** — это нормально. Заявки уходят только с **формы заказа** на сайте.

Оформите тестовый заказ на сайте. Сообщение должно прийти в Telegram.

Если ошибка «Telegram не настроен» — проверьте `telegram.env` и перезапустите `server.py`.
