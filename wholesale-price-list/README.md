# Оптовый прайс-лист порционных десертов

Одностраничный PDF для оптовых клиентов.

## Содержимое

| Десерт | Вес | Цена | Фуршет |
|--------|-----|------|--------|
| Баскский чизкейк | 110 г | 180 ₽ | — |
| Медовик | 120 г | 180 ₽ | 30 г / 120 ₽ |
| Армянская птичка | 120 г | 160 ₽ | 30 г / 120 ₽ |
| Меренговый рулет | 120 г | 160 ₽ | — |
| Морковный торт | 120 г | 180 ₽ | — |
| Профитроли с заварным кремом | 1 шт | 35 ₽ | — |

## Файлы

- `price-list.pdf` — готовый прайс
- `price-list.html` — исходник вёрстки
- `photos/` — исходные и стилизованные фото
- `photos/cropped/` — квадратные кадры для PDF

## Пересборка PDF

```bash
python3 -c "from weasyprint import HTML; HTML('price-list.html').write_pdf('price-list.pdf')"
```

Требуется: `pip install weasyprint pillow`
